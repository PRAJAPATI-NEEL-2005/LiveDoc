Theory of Computation 1-7 Review of Mathematical Theory
Let us discuss each one by one -

### i) Negation

This proposition is also called NOT proposition. It is denoted by 1 or  or having
horizontal bar on letter.
If S is a proposition then ¬S defines NOT s. The truth table for this connective is

| S | ¬S |
| :---: | :---: |
| T | F |
| F | T |

### ii) Conjunction (AND)

If A and B are two propositions then conjunction of A and B is denoted by A ∧ B.The
truth table for this connective is

| A | B | A ∧ B |
| :---: | :---: | :---: |
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | F |

### iii) Disjunction (OR)

If A and B are two propositions then disjunction of A and B is denoted by A ∨ B. The
truth table for this connective is

| A | B | A ∨ B |
| :---: | :---: | :---: |
| T | T | T |
| T | F | T |
| F | T | T |
| F | F | F |
